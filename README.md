# Вариант 1 — Консольный калькулятор

Программа выполняет арифметические операции: `+`, `-`, `*`, `/`, `//`, `%`, `^`.

Обрабатываются неизвестные операции и деление на ноль.

## Запуск
```bash
python main.py
```

## Пример
Введите первое число: 15
Введите операцию: *
Введите второе число: 4
Результат: 60
